Scan a code to enter the gallery

ExhibitGuide is designed for a visitor standing in front of an artwork. Each code below sits beside a work on the gallery wall — scanning it opens that piece's page instantly. No app to install, no account needed.

How to try it

  1. Open your phone's camera Any modern iPhone or Android camera reads QR codes — no separate app.
  2. Point it at any code below Hold steady until a notification appears, then tap it.
  3. The artwork's page opens Read about the piece, play the audio guide, and browse the details — all without signing in.
  4. Express interest in a work Tap Express Interest in Purchasing and leave an email. This is the gallery's lead capture — it records the enquiry, the artwork, and how long you spent with it.
  5. Create an account to keep a collection Registering saves the works you scan, so you can revisit them and enquire from your dashboard.

No phone to hand? Select any code below and it will open in this browser — exactly what a scan does. The pages are built mobile-first, so narrowing your window (or using your browser's device view) best reflects the real experience.
